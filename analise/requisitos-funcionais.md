+ RF-001: O sistema deve permitir que os participantes visualizem todos os eventos disponíveis em um único local.
+ RF-002: O sistema deve permitir que os participantes se inscrevam em eventos e workshops.
+ RF-003: O sistema deve emitir um comprovante de inscrição imediatamente após a confirmação da inscrição.
+ RF-004: O sistema deve permitir que o participante cancele sua inscrição sem necessidade de contato manual com a organização, dentro de um prazo previamente definido.
+ RF-005: O sistema deve permitir que o participante emita seu certificado após o evento, quando houver confirmação de participação.
+ RF-006: O sistema deve permitir a inscrição em vários workshops no mesmo dia, desde que não haja conflito de horário.
+ RF-007: O sistema deve controlar automaticamente as vagas disponíveis e informar quando um evento atingir a capacidade.
+ RF-008: O sistema deve criar automaticamente uma lista de espera quando um evento estiver lotado.
+ RF-009: O sistema deve permitir que os organizadores acompanhem, em tempo real, a quantidade de inscritos por evento.
+ RF-010: O sistema deve permitir que os organizadores consultem a lista de participantes inscritos em suas atividades.
+ RF-011: O sistema deve bloquear ou aguardar confirmação do pagamento antes de liberar inscrições em eventos pagos.
+ RF-012: O sistema deve permitir que a equipe financeira confirme pagamentos e acompanhe reembolsos.
